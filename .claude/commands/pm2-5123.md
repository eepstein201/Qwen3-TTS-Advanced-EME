Start TTS server (5123) and open logs.

```bash
cd "/Users/ericepstein/Qwen3-TTS_UserFiles" && pm2 start ecosystem.config.cjs --only tts-server-5123 && pm2 logs tts-server-5123
```

## Observation

`pm2 logs` streams the app's stdout/stderr (same content as `~/.pm2/logs/tts-server-5123-out.log`); the server's own log is `.voice_server.log` in the repo root. Model loading progress and warm-up lines appear here.

## Feedback

Success: the app shows `online` with a fresh uptime in `pm2 status`, and `curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:5123/health` returns `200` (or `503` while models are still loading). Failure: `errored`/`restarts` climbing fast — check the streamed log for a Python traceback.

## Rollback

Undo the start: `/pm2-5123-stop` (`pm2 stop tts-server-5123`). Changes to this command file itself: `git revert <commit>` on the branch that touched it.
