CODE CHANGES ANALYZED (NOT EDITED; GROUND TRUTH FOR DOCS):
===========================================================

New module: qwen3_tts/core/config/pm2.py (128 LOC)
  - pm2_owner_of_port(port: int) → str | None
    * Finds listening PID on port via find_pid_by_port()
    * Walks parent chain (up to 10 levels) against pm2 jlist online apps
    * Returns matching app name or None
  - pm2_registered_app(port: int) → str | None
    * Queries pm2 jlist for any registration (online or stopped)
    * Matches by naming convention "tts-server-<port>"
    * Returns app name or None
  - Lazy subprocess imports; no heavy dependencies

Modified: qwen3_tts/cli_server.py
  - start() command: calls pm2_registered_app(port) → delegates to _start_via_pm2() if registered
  - stop() command: calls pm2_owner_of_port(port) → delegates to _stop_via_pm2() if online
  - restart() command: calls pm2_owner_of_port(port) → delegates to _restart_via_pm2() if online
  - --foreground flag remains non-PM2 escape hatch (Colab/notebooks)
  - --public flag now warns-and-ignored under PM2 (ecosystem.config.cjs is the authority)

Modified: qwen3_tts/interface/ui/_facade.py
  - New helper: _stop_server_via_pm2(name, client)
    * Mirrors cli_server._stop_via_pm2 behavior; subprocess.run(["pm2", "stop", name])
    * Polls is_server_running() to confirm stop (up to 5 seconds)
  - stop_server() entrypoint: calls pm2_owner_of_port(port) → delegates to _stop_server_via_pm2() if detected
  - Fallback: POST /shutdown if no PM2 detected
