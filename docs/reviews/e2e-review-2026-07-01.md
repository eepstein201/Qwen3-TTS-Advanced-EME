## Findings (severity-ranked)

### Fixed in this branch
- **[MEDIUM→resolved] `server/app_lifespan.py:113` unguarded `psutil.virtual_memory()`.**
  Guarded only by `_HAS_PSUTIL` import-presence, not runtime error. On macOS it
  intermittently raised `host_statistics64 … array not large enough` under load —
  the sole failure source across the full suite (11/2269), and on the generation path
  (`_check_memory_available`) it could 500 a request. Wrapped in try/except → graceful
  fallback mirroring the no-psutil branch. Verified: batch 2 4 errors → 479 OK.

### HIGH (recommend fixing; behavioral → gated for approval)
- **Token-write failure continues startup — `server/app_lifespan.py:304`.** On write
  failure the server logs ERROR and continues; the comment "client will use alternative
  auth" is false (TTSClient reads the token only from this file), so all authed endpoints
  become unusable. Availability-only, rare trigger. Fix: fail-fast `raise`.
- **`/cancel-generation` may not stop streaming — `app.py:559` / `app_generation.py:580`.**
  Sets `generation_state["cancelled"]` but the streaming thread checks `stop_event`;
  nothing bridges them. Verify against engine layer + the E2E cancel test before fixing.
- **Blocking I/O on the event loop.** Four prompt endpoints call sync handlers without
  `asyncio.to_thread` (`app.py:496,507,518,534`); `load_voice_prompt()` runs sync in async
  context (`app_generation.py:241,501`); WAV-encode + peaks run inside the inference lock
  (`app_generation.py:335-368`). Inconsistent with load-model/transcribe which wrap
  correctly. Fix: `await asyncio.to_thread(...)` / release lock before serialize.
- **`eval()` of inline DOM scripts — `interface/wavesurfer_js.py:47`.** DOM-XSS amplifier;
  the module-script branch already uses the safe `Blob`+`createObjectURL` pattern — apply
  it to the inline branch.
- **WaveSurfer CDN without SRI — `wavesurfer_js.py:68`** (`unpkg.com/...@7`, floating).
  Pin + `integrity` + `crossorigin`, or self-host.
- **`/ws` WebSocket has no rate limiting — `app.py:635`.** accept() precedes auth; each
  conn pins an FD for the 10s auth window. In `--public`/Colab an unauth flood exhausts
  FDs. Enforce a per-IP connection cap before accept().

### MEDIUM
- **Silent error swallowing** (add logging; `app_prompts.py:118,210` config default not
  updated after delete/rename; `app_models.py:360` audio-loader cache sync; `ui/shared.py:160,196`
  model probe/reload; `config.py:448` voice-dir scan; `client/voices.py:34` server→fs fallback).
- **X-Forwarded-For trusted from any non-loopback conn — `app.py:148-156`.** Rotating fake
  XFF bypasses per-IP rate-limit key in public/Colab. Add a `trusted_proxies` allowlist.
- **Public `/generation-status` leaks eta/batch_total — `app.py:354-372`** (text-length

- **vLLM clone temp file never cleaned — `vllm_client.py:231`** (`delete=False`, no finally).

- **19/21 endpoints lack `response_model`** → near-empty OpenAPI schema.
- **Structural debt:** `config.py` 1432 lines, `_facade.py` 1293, `inference.py` 1097,

  `except Exception` too broad at `inference.py:627,637`. f-string logging (eager format)
  at several sites. Duplicate module logger `engine_vllm.py:34`/`:76`. Unguarded file
  handle `engine_vllm.py:268`.
