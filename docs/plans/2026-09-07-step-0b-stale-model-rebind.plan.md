# Step 0B: Stale model reference after unload→reload — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development — a fresh implementer subagent per task, a two-verdict review (spec + quality) after each, and a broad final review before handoff. The controller (the main session) never implements; it dispatches, reviews, and rules. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every inference path run against the model object occupying `state.models[mode]` *at lock-acquisition time*, not the one captured before it — so an unload→RELOAD interleaving inside the capture→acquire window can never run inference on the orphaned pre-unload object.

**Architecture:** Convert `_require_model_under_lock(state, mode)` from a null-check guard (`-> None`) into a guard-and-return (`-> Any`): raise the unchanged retryable 503 when the slot is None, otherwise return the re-read slot. Rebind the caller's local from the return value at all four capture paths — batch (`app_generation.py:436`), stream (`:835`), WS (`websocket.py:486`), and `/create-voice-prompt`'s torch path (`app_prompts.py`, which has **no** post-lock recheck today and gets guard+rebind). Python closure cells are shared, not frozen: rebinding the enclosing scope before `thread.start()` is what makes the inference threads see the fresh object (verified per-site; see Scope-safety).

**Tech Stack:** Python 3.10+, FastAPI/asyncio (`asyncio.Lock`), pytest running plain `unittest.TestCase` classes, `MagicMock` slot-swap injection (no GPU, no models, no server).

**Spec:** `docs/plans/2026-09-06-consolidated-backlog-priority.plan.md` — Wave 0, Step 0B. The consolidated plan's Step 0B text predates re-verification: the guard is at `app_generation.py:129-160` (not 127-158), there are **four** capture paths and **three** existing guard sites (not five), and the WS consumer is `inference_thread` at `websocket.py:416-433` with the guard at `:486`.
